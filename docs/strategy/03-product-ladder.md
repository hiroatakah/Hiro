# 03. 商品ラダー：6階建て Land & Expand 構造

> **本ドキュメントは OneWay の全商材の定義書です。**
> ここにない商品は売りません。ここにある商品は、必ず「次のLevelへの入口」として設計します。

---

## 1. 結論：同じ会社の契約単価を、5段階で上げ続ける

> **新規顧客を追い続ける会社は、永遠に営業し続けます。**
> **既存顧客の単価を上げる会社は、営業しなくても成長します。**

これが OneWay版 Land & Expand です。1社を Level 0 で獲得し、5年かけて Level 5 まで引き上げます。

## 3. 各Levelの定義

### Level 0 — Executive AI Briefing（50〜100万円 / 半日〜1日）

**目的：有料で経営陣の時間を確保し、「無料提案を待つ会社」を排除します。**

| 項目 | 内容 |
|---|---|
| 対象 | 社長 + 役員3〜8名 |
| 形式 | 経営合宿・役員会枠での半日〜1日セッション |
| 内容 | ① 業界のAI活用の現在地 ② 他社事例（同業種） ③ **自社に当てはめたときの適用領域の粗い洗い出し** ④ 3年後に起きること ⑤ 次の一手の選択肢 |
| 成果物 | ブリーフィング資料 / 適用領域の初期マップ / 論点整理メモ |
| **戦略的役割** | **Level 1（Assessment）への転換装置。** 単体で利益を狙いません |

**なぜ有料か：** 無料セミナーには「情報収集だけの役員」が来ます。50万円払った企業の役員は、**その場で次の意思決定をしようとします。**

**次への転換：** セッション最後に必ず Assessment を提案します。目標転換率 **40%**。

---

### Level 1 — Enterprise AI Assessment（300万円 / 4〜6週間）★営業商品★

**このラダー全体の心臓部です。ここが売れれば、上は自動的に売れます。**

| 項目 | 内容 |
|---|---|
| 対象 | 社長・経営企画・DX責任者 |
| 期間 | 4〜6週間 |
| 体制 | Hiro（アーキテクト） + アナリスト1名 |

**実施内容（9工程）：**

| # | 工程 | 内容 |
|---|---|---|
| 1 | 経営陣ヒアリング | 中期経営計画・経営課題・人員計画（社長＋役員3〜5名） |
| 2 | 部門長ヒアリング | 業務実態・ボトルネック（5〜10部門） |
| 3 | 業務棚卸し | 全ホワイトカラー業務の洗い出しと工数実測 |
| 4 | AI適用可能性評価 | 業務ごとの適用可否・難易度・効果を3軸評価 |
| 5 | セキュリティ評価 | 現行の情報管理体制・リスク・必要な統制 |
| 6 | データ評価 | 社内文書・システムデータの所在・品質・接続可否 |
| 7 | 投資対効果試算 | 削減時間・金額換算・投資回収期間 |
| 8 | **AI Architecture 設計** | 7層アーキテクチャに基づく自社構成の設計（[04-architecture.md](04-architecture.md)） |
| 9 | 3年ロードマップ | 導入順序・投資計画・体制計画 |

**最終報告は、必ず経営会議で実施します。** これが商品設計上の最重要要件です。

**成果物の目標フォーマット（数字の例）：**

```
┌────────────────────────────────────────┐
│  AI適用候補業務        87業務            │
│  年間削減可能時間      24,000時間        │
│  推定経済効果          年間1.4億円        │
│  初年度AI投資          3,000万円          │
│  投資回収期間          8.3か月            │
└────────────────────────────────────────┘
```

**この報告書が作り出す意思決定の質的転換：**

| ❌ 300万円を払った企業が考えること（悪い設計） | ✅ 実際に考えさせること（正しい設計） |
|---|---|
| 「システムに3,000万円払うか？」 | **「1.4億円の経済効果を取りにいくか？」** |
| コストの意思決定 | **投資の意思決定** |
| 情シス・購買の管轄 | **経営会議の管轄** |

> **300万円のAssessmentは、「診断書」を売っているのではありません。「経営会議の議題」を売っています。**

**次への転換：** 目標 **60%**（Level 2 または Level 3 へ直行）

---

### Level 2 — AI Proof of Value（500〜800万円 / 8〜12週間）

**PoCではありません。PoV（Proof of Value = 価値の証明）です。この言葉の違いが商品性を決めます。**

| PoC（やってはいけない） | **PoV（OneWayが売るもの）** |
|---|---|
| 技術的に動くかを確認する | **経営効果が出るかを実測する** |
| 成功しても本番に進まない | **本番移行を前提に設計する** |
| 情シスが評価する | **経営会議が評価する** |
| 「動きました」で終わる | **「年間◯◯時間削減」を数字で出す** |

| 項目 | 内容 |
|---|---|
| 対象業務 | Assessment で特定した優先3業務 |
| 対象部門 | 1〜2部門 / 20〜50名 |
| 期間 | 8〜12週間 |
| 成果物 | 稼働エージェント3種 / 効果実測レポート / 全社展開計画 |

**必須の契約条項：** 契約書に「効果目標値」と「達成時の Level 3 移行条件」を明記します。**PoVを単体で終わらせないための構造的な仕掛けです。**

**次への転換：** 目標 **70%**

> **PoVの最大リスクは「やって終わり」です。** 効果が出ても、次の予算期まで待たされると熱が冷めます。**PoV開始時点で、Level 3 の予算枠を確保させておくこと**が営業側の必須動作です。

---

### Level 3 — Department AI Platform（1,000〜2,000万円 / 年間契約）

**ここから継続収益（ARR）が始まります。ラダーの分水嶺です。**

| 項目 | 内容 |
|---|---|
| 対象 | 1〜3部門 / 100〜300ユーザー |
| 内容 | Platform 本体 + エージェント10〜20種 + Knowledge Hub + Governance + Control Center |
| 契約 | 年間契約・年額前払い・自動更新 |
| 支援 | 月次伴走 + 四半期レビュー |

**戦略的役割：** 全社展開（Level 4）の**成功事例を社内に作る**こと。他部門から「うちにも」と言わせる状態を作ります。

**次への転換：** 目標 **40%**（1年目の実績を持って全社提案へ）

---

### Level 4 — Enterprise AI Platform（3,000〜8,000万円 / 年間契約）

| 項目 | 内容 |
|---|---|
| 対象 | 全社 / 500〜2,000ユーザー |
| 内容 | 全機能 + エージェント無制限 + 全社ガバナンス + SSO/監査API + 専任アーキテクト |
| 契約 | 年間契約（初年度は構築費を含む） |
| 決裁 | 経営会議・取締役会 |

**価格レンジの根拠：**

| 従業員規模 | 想定価格 |
|---|---|
| 100〜300名 | 3,000万円 |
| 300〜800名 | 5,000万円 |
| 800〜2,000名 | 8,000万円 |

---

### Level 5 — Enterprise Agreement（年3,000〜8,000万円 × 3年）

**複数年包括契約。OneWayにとっての「勝ち確定」の状態です。**

| 項目 | 内容 |
|---|---|
| 契約形態 | 3年コミット（年額前払い or 年次前払い） |
| 含むもの | Platform 全機能 + **AI Capacity 大容量枠** + **Marketplace エージェント使い放題枠** + プレミアムサポート + **グループ会社展開権** |
| 顧客側のメリット | 単年契約より15〜20%割安 / 予算の複数年確定 / 優先サポート |
| OneWay側のメリット | **3年分のARR確定** / 解約リスクの消滅 / 企業価値評価の大幅向上 |

**Level 5 の本質は「値上げ」ではなく「期間の固定」です。** 単年で8,000万円取るより、3年で2.1億円を確定させるほうが、事業価値は圧倒的に高くなります。

---

## 4. Land & Expand の実数モデル（1社あたり5年累積）

| 年 | Level | 金額 | 累積 |
|---|---|---|---|
| Y1上期 | 0 Briefing | 75万円 | 75万円 |
| Y1下期 | 1 Assessment | 300万円 | 375万円 |
| Y2上期 | 2 PoV | 650万円 | 1,025万円 |
| Y2下期〜Y3 | 3 Dept Platform | 1,500万円 × 2年 | 4,025万円 |
| Y4 | 4 Ent Platform | 5,000万円 | 9,025万円 |
| Y5 | 5 Ent Agreement | 年4,000万円（3年コミット初年度） | **1.3億円** |
| （Y6-Y7） | 5 継続 | 年4,000万円 × 2 | （2.1億円） |

> **1社を5年かけて育てると、累積1.3億円。7年で2.1億円になります。**
> **10社育てれば、それだけで累積13億円です。**

**この数字が意味すること：新規開拓に使うべき労力は、多くの会社が思っているより少なくて済みます。** OneWayが追うべきは「今年何社取ったか」ではなく「既存◯社を次のLevelに上げられたか」です。

## 5. Level間の転換を「仕込む」設計

**転換は営業努力ではなく、商品設計で起こします。**

| 転換 | 仕込み方 |
|---|---|
| 0 → 1 | Briefing の最後に「適用領域の初期マップ」を提示し、**「精緻化にはAssessmentが必要」**と構造的に示します |
| 1 → 2/3 | Assessment 報告書に**3年ロードマップと初年度投資額を明記**します。次の意思決定が報告書の中にあります |
| 2 → 3 | **PoV契約書に効果目標値とLevel 3移行条件を明記**します |
| 3 → 4 | Control Center で**部門実績を可視化**し、他部門長に見せます。社内から要望を上げさせます |
| 4 → 5 | 単年更新時に**3年契約の15〜20%割引**を提示します。CFOが飛びつく条件設計にします |

## 6. 各Levelの「止まりやすいポイント」と対策

| Level | 止まる理由 | 対策 |
|---|---|---|
| 0 | 役員が集まらない | 社長にだけ売る。役員招集は社長にやらせます |
| 1 | 「300万円は高い」 | Level 0 を先に売る。無料提案は絶対にしません |
| 1→2 | 報告書が「読み物」で終わる | **経営会議での報告を契約に含める**（メール納品を禁止） |
| 2 | PoVで効果が出ない | 対象業務の選定を誤っています。効果の出やすい定型文書業務から始めます |
| 2→3 | 次年度予算がない | PoV開始時に予算枠を確保させます |
| 3 | 利用が広がらない | 週次アクティブ利用率40%を死守。40%割れは即介入します |
| 3→4 | 他部門が動かない | Control Center の実績を役員会に出します。横展開は社長に言わせます |
| 4→5 | 単年で十分と言われる | CFOに複数年割引と予算平準化のメリットを直接説明します |

## 7. 【要決定】Level 4 と Level 5 の価格整合について

**現行の指示では、Level 4（3,000〜8,000万円）に対して Level 5（年1,000〜3,000万円）が安くなっており、「同じ会社の契約単価が上がる」というラダーの原則と矛盾します。**

考えられる解釈と、推奨する整理を以下に示します。

| 解釈 | 内容 | 評価 |
|---|---|---|
| A | Level 4 = 初年度総額（構築費込み）/ Level 5 = 2年目以降の年額 | 自然な解釈ですが、**単価が下がるため Expand になりません** |
| B | Level 5 = Level 4 への**追加アドオン**（Capacity / Agent / Support）年1,000〜3,000万円 | 加算されるので整合します。ただし「Enterprise Agreement」という名称と合いません |
| **C（推奨）** | **Level 5 = 複数年包括契約。年額は Level 4 と同等以上（年3,000〜8,000万円）× 3年コミット。グループ会社展開権・Marketplace枠・プレミアサポートを包含** | **単価が下がらず、期間が固定され、事業価値が最大化します** |

**推奨：C を採用します。** 本ドキュメントは C を前提に記述しています。

**Hiroの判断が必要です。** B を採るなら Level 5 の名称を「Enterprise Add-on」に変更し、C を採るなら現行の価格表記を修正します。→ [10-decision-log.md](10-decision-log.md) に記録してください。
