# 10. 意思決定ログ

> **決めたことと、決めた理由を残します。**
> 3ヶ月後に「なぜこうしたんだっけ」と迷わないため、そして前提が変わったときに再検討できるようにするためです。

**記入ルール：** 戦略・価格・商品・組織に関わる決定は、その日のうちにここへ追記します。**決めていないことは「未決」と書きます。**

---

## 記入フォーマット

```markdown
### D-XXX ｜ YYYY-MM-DD ｜ 決定タイトル
- **論点：** 何を決める必要があったか
- **選択肢：** A / B / C
- **決定：** 採用した選択肢
- **理由：** なぜそれを選んだか
- **前提：** この決定が依拠している前提（変わったら再検討する）
- **影響範囲：** 変更が必要になる文書・資産
- **再検討トリガー：** どうなったら見直すか
```

## 決定一覧

### D-001 ｜ 2026-08-29 ｜ 事業アイデンティティを Enterprise AI Architecture Company に変更
- **論点：** OneWayは何の会社として市場に立つか
- **選択肢：** A) AIコンサル → AI導入支援 → 業務自動化（サービス積み上げ型） / B) Enterprise AI Architecture Company（レイヤー保有型）
- **決定：** **B**
- **理由：** Aは3つとも人月に依存し、売上上限が人数で決まる。資産が残らず、差別化もできない。Bは「設計と標準を保有する」ため、従業員を増やさずに高単価を扱える
- **前提：** 設計・標準を保有できる実体（EL1〜EL3）を実際に作れること
- **影響範囲：** 全文書 / 会社紹介 / 提案書 / 採用要件
- **再検討トリガー：** EL2（Platform）が2年経っても顧客別コードから脱却できない場合

### D-002 ｜ 2026-08-29 ｜ ターゲットを売上30〜500億円・従業員100〜2,000名に設定
- **論点：** どの規模帯の企業を狙うか
- **選択肢：** A) 従業員100〜500名の中小オーナー企業 / B) 売上30〜500億円・従業員100〜2,000名の中堅企業 / C) 売上1,000億円超の大企業
- **決定：** **B**
- **理由：** 大手コンサルは採算が合わず本気で来ない。零細AIベンダーは経営レベルで話せない。この帯は「大手には相手にされず、ベンダーには理解されない」空白地帯。かつ年間3,000万〜1億円のIT投資ができる
- **前提：** 与信・購買審査を紹介ルートとホワイトペーパーで突破できること
- **影響範囲：** [02-icp-target.md](02-icp-target.md) / [07-gtm-playbook.md](07-gtm-playbook.md) / 価格表
- **再検討トリガー：** 成約10社時点で、実際の成約企業の規模分布が想定と大きくズレた場合

### D-003 ｜ 2026-08-29 ｜ 接触対象を経営層に限定（現場担当を窓口にしない）
- **論点：** 誰にアプローチするか
- **決定：** 社長・取締役・経営企画・DX責任者に限定。現場担当が窓口の案件は、経営層への説明機会を条件とする
- **理由：** 現場から入った案件は必ず「ツール比較」に落ち、価格競争になる
- **影響範囲：** [02-icp-target.md](02-icp-target.md) 第5・6章 / KPI「初回面談の経営層比率」
- **再検討トリガー：** 経営層比率70%を維持しても受注率が5%を下回る場合

### D-004 ｜ 2026-08-29 ｜ 商品を6階建てラダー（Level 0〜5）にする
- **論点：** 商品構成をどうするか
- **決定：** Level 0 Briefing（50〜100万）/ 1 Assessment（300万）/ 2 PoV（500〜800万）/ 3 Dept Platform（1,000〜2,000万）/ 4 Ent Platform（3,000〜8,000万）/ 5 Ent Agreement
- **理由：** 同一顧客の契約単価を段階的に上げる Land & Expand。新規獲得より既存拡大のほうがCACが低く成約率が高い
- **影響範囲：** [03-product-ladder.md](03-product-ladder.md) / [06-revenue-model.md](06-revenue-model.md) / 契約書ひな形
- **再検討トリガー：** Level間の転換率が目標の半分を下回る場合

### D-005 ｜ 2026-08-29 ｜ Assessment を300万円の有償営業商品とし、無償提案を禁止
- **論点：** 入口商品をどう設計するか
- **決定：** Enterprise AI Assessment 300万円 / 4〜6週間 / **最終報告は経営会議で実施（契約書に明記）**
- **理由：** ① 投資意思のある企業を選別できる ② 報告書が稟議書の下書きになる ③ 「システムに3,000万円払うか」ではなく「1.4億円を取りにいくか」という意思決定に転換できる
- **前提：** 4〜6週間で経営会議に出せる品質の報告書を作れること
- **影響範囲：** [07-gtm-playbook.md](07-gtm-playbook.md) 第5・6章 / [06-revenue-model.md](06-revenue-model.md) 値引き禁止事項
- **再検討トリガー：** Briefing → Assessment 転換率が20%を下回る場合

### D-006 ｜ 2026-08-29 ｜ 課金構造を「固定 + 従量 + オプション」の複合型にする
- **論点：** 課金モデルをどうするか
- **選択肢：** A) 席数課金 / B) 純粋従量 / C) 固定コミット + 従量 + オプション
- **決定：** **C**
- **理由：** 席数課金は使わない席への課金で定着率が落ちる。純粋従量は予算が読めず顧客が利用を抑制する
- **前提：** クレジット原価を基本料金の15%以内に収められること
- **影響範囲：** [06-revenue-model.md](06-revenue-model.md) 全体
- **再検討トリガー：** 顧客別のAI原価率が20%を超えた場合

### D-007 ｜ 2026-08-29 ｜ T7（モデル・インフラ）は絶対に自社開発しない
- **論点：** 独自モデルを開発するか
- **決定：** **開発しない。** 外部モデルをルーターで抽象化して使う
- **理由：** 費用対効果が合わない。差別化はT1（経営可視化）・T5（統制）・T2（業種別の型）にある。モデルは3年で陳腐化するが、業務知識とガバナンス設計は陳腐化しない
- **影響範囲：** [04-architecture.md](04-architecture.md) 第2・6章 / 採用要件 / 対外説明
- **再検討トリガー：** 外部モデルの規約・価格が事業継続を脅かす水準に変化した場合

### D-008 ｜ 2026-08-29 ｜ 「1期に着手する事業レイヤーは1つまで」を原則とする
- **論点：** EL1〜EL6 をどの順序・速度で立ち上げるか
- **決定：** Y1=EL1+EL2 / Y2=+EL3 / Y3=+EL4 / Y4=+EL5 / Y5=+EL6
- **理由：** 構想が壮大なほど「全部同時」の誘惑が強い。少人数では全部が中途半端になる
- **影響範囲：** [08-execution-plan.md](08-execution-plan.md) / 採用計画 / 開発ロードマップ
- **再検討トリガー：** 前レイヤーの合格判定が前倒しで達成された場合のみ、次を前倒し検討

### D-009 ｜ 2026-08-31 ｜ ブランドを「OneWay Enterprise AIOS」に確定
- **論点：** 対外ブランド・カテゴリー・名乗り
- **決定：** カテゴリー＝**Enterprise AI Operating System**、ブランド＝**OneWay Enterprise AIOS**、タグライン＝**人とAIが共に働く会社の経営基盤**、名乗り＝**AI Workforce Design Company（人とAIの労働力設計会社）**。旧称「OneWay Enterprise AI Platform」「Enterprise AI Architecture Company」は本日をもって置換
- **理由：** 「Platform」はツールに聞こえる。「AIOS＝経営OS」は管理対象（人/AI/業務/権限/判断/経営成果）まで含む上位カテゴリーを主張でき、下位レイヤー（Copilot/Agentforce等）を競合ではなく部品にできる
- **前提：** 「Ai Workforce」はLayerXの製品名であるため、商標調査（A-11）の結果次第で表記を調整
- **影響範囲：** 全文書 / overview.html / スキル / 今後の提案書・LP
- **再検討トリガー：** 商標調査で重大な支障が出た場合

### D-010 ｜ 2026-08-31 ｜ 売上コミット目標を FY2027 5,000万 / FY2028 1億 / FY2029 3億 に設定
- **論点：** 経営目標の水準と正となる計画文書
- **決定：** 上記3年目標をコミットとし、**[13-goal-plan-3y.md](13-goal-plan-3y.md) を唯一の正**とする。06/08の5年モデルは上振れシナリオに降格
- **理由：** 旧モデル（Y1で1.02億）は体制1〜3名に対して過大。5,000万→1億→3億は月5面談・Platform年1〜5社で成立する実行可能な水準
- **再検討トリガー：** 2四半期連続±20%乖離

### D-011 ｜ 2026-08-31 ｜ 補助金活用のコンプライアンス・ファイアウォールを制定
- **論点：** ライトアップ型「補助金レバレッジ」を導入するか（同社には2026年3月に不正受給指南の疑惑報道あり）
- **決定：** 導入する。ただし5原則を社内規範とする：①補助金は提案の前提にしない ②申請は認定支援機関・士業のみ ③「必ず通る」「実質無料」禁句 ④粉飾関与は取引打ち切り ⑤補助金関連売上は全社の10%以下
- **理由：** 経営層に信頼で売る事業は、一度の報道で全案件を失う。構造は移植し、リスクは遮断する
- **影響範囲：** [12](12-benchmark.md) 2.4 / [07](07-gtm-playbook.md) / 営業研修
- **再検討トリガー：** なし（恒久規範）

### D-012 ｜ 2026-08-31 ｜ 2エンジン体制（獲得＝ライトアップ型／拡大＝LayerX型）を採用
- **決定：** Level 0〜1への集客はライトアップ型（診断・ウェビナー・紹介網・補助金）、Level 3〜5の販売はLayerX型（コンパウンド・灯台顧客・借景・公開文化）で構築する。紹介パートナー網はFY2027に前倒し（実装パートナー＝EL4はFY2029のまま）
- **理由：** [12-benchmark.md](12-benchmark.md) 第0章
- **影響範囲：** [13](13-goal-plan-3y.md) 第2章の施策G-1〜5 / K-1〜5

## 未決事項（決めるべきなのに決まっていないこと）

### U-001 ｜ Level 4 と Level 5 の価格整合 【最優先・Phase 0 W1で決着】
- **論点：** Level 4（3,000〜8,000万円）に対し Level 5（年1,000〜3,000万円）が安く、ラダーの原則と矛盾している
- **選択肢：** A) Level 5 = 2年目以降の年額 / B) Level 5 = Level 4へのアドオン（年1,000〜3,000万円） / C) Level 5 = 複数年包括契約、年額は Level 4 同等以上 × 3年コミット
- **推奨：** **C**（単価が下がらず、期間が固定され、事業価値が最大化する）
- **決定者：** Hiro
- **期限：** Phase 0 W1（2026年9月第1週）
- **詳細：** [03-product-ladder.md](03-product-ladder.md) 第7章

### U-002 ｜ 重点8業種のうち、最初に密度を作る2業種の選定
- **論点：** 8業種すべてを同時に攻めると、業種別テンプレートの蓄積が薄まる
- **判断材料：** 既存クライアントの業種分布 / 紹介ルートの強さ / 業務の標準化しやすさ
- **期限：** Phase 0 完了時（2026年11月）

### U-003 ｜ デザインパートナー価格の割引幅
- **選択肢：** A) 50%（事例2社を最速で作る） / B) 30% / C) 値引きせず90日オプトアウトのみ
- **前提条件：** いずれの場合も、翌年以降の価格階段を契約書に明記すること
- **期限：** 初号商談前

### U-004 ｜ 増資の要否と時期
- **論点：** 資本金90万円は、この帯の企業の与信審査で不利に働く可能性がある
- **判断材料：** 実際に与信で落ちた件数 / 紹介ルートでの突破率
- **期限：** Assessment 5件実施後に判断

### U-005 ｜ 既存受託事業（OWL / Executive AI Camp / Udemy等）との関係整理
- **論点：** B2C教育事業とB2Bエンタープライズ事業を、同一ブランドで運営するか分離するか
- **論点の中身：** エンタープライズ顧客から見たとき、B2C教育事業の存在が信頼を上げるか下げるか
- **期限：** Y1中
