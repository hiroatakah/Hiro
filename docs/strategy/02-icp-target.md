# 02. ターゲット定義（ICP）：誰に売るか

> **本ドキュメントは OneWay の営業活動すべての前提です。**
> ここに定義した条件から外れる企業は、どれだけ引き合いが来ても追いません。

## 1. 結論：狙う企業の定義

> **売上30〜500億円 / 従業員100〜2,000名の日本企業。**
> **ホワイトカラー業務が大量にあるが、AI専門部署が弱い企業。**
> **接触するのは、社長・取締役・経営企画・DX責任者に限定します。**

**現場担当者には一切アプローチしません。** 現場から入った案件は、必ず「ツール比較」に落ちて価格競争になります。

---

## 2. なぜこの帯なのか — 市場の空白地帯

```
売上1,000億円〜        │ 大手コンサル・大手SIerの陣地
                      │ （総合コンサル / 大手SI / 各社DX部門）
                      │ → 提案1本で数千万〜数億円。OneWayは戦えません
──────────────────────┼──────────────────────────────────
売上30〜500億円        │ ★★★ 空白地帯 ★★★
従業員100〜2,000名     │ ・大手コンサルは採算が合わず本気で来ません
                      │ ・零細AIベンダーは経営レベルの会話ができません
                      │ ・社内にAI専門部署がなく、内製できません
                      │ ・しかし年間3,000万〜1億円のIT投資はできます
──────────────────────┼──────────────────────────────────
売上30億円未満         │ 零細AIベンダー・ツール販売の陣地
                      │ → 予算が3桁万円。エンタープライズ商材が入りません
```

**この帯の企業は、「大手コンサルには相手にされず、AIベンダーには経営課題を理解されない」という不満を抱えています。**

OneWay は次の2点を同時に満たす、この帯にとって数少ない選択肢になります。

1. **大手コンサルほど高額ではない**（Assessment 300万円 / Platform 3,000万円〜）
2. **零細AIベンダーと違い、経営レベルで話せる**（社長と事業戦略の言葉で会話できる）

## 3. 重点業種と、そこで刺さる業務

### 3.1 重点8業種

| 業種 | なぜ刺さるか |
|---|---|
| **不動産** | 契約書・重説・物件資料・問い合わせ。文書業務の塊。かつ属人化が激しい |
| **小売・多店舗** | 本部⇔店舗の報告・集計業務が膨大。店舗数だけ工数が線形に増えます |
| **医療周辺**（医療法人 / 調剤 / 医療機器 / 検査） | 事務職比率が高く、規制文書が大量。ただし医療行為そのものには触れません |
| **介護** | 記録・ケアプラン・請求事務。人手不足が経営課題の第1位 |
| **物流** | 配車・請求・荷主対応・安全書類。ドライバー不足で事務効率化が急務 |
| **建設** | 見積・施工計画・安全書類・下請管理。書類量が業界随一 |
| **人材** | 求人票・スカウト・面談記録。1人あたり生産性が売上に直結します |
| **多店舗サービス**（飲食 / 美容 / 整骨院 / 学習塾 / フィットネス） | SV業務・マニュアル・研修。標準化への渇望が強い |

### 3.2 業種別・最初に刺さる業務と経営指標（提案の入口）

**この表を持って商談に入ります。「御社の業界では、ここから始めるのが最短です」と言えることが最大の武器です。**

| 業種 | 業務の集中点 | 最初に導入するエージェント | 接続する経営指標 |
|---|---|---|---|
| 不動産 | 問い合わせ対応 / 契約書チェック / 物件資料作成 | 問い合わせAI・契約書確認AI・物件資料AI | 反響初動対応時間 → 成約率 |
| 小売・多店舗 | 店舗日報の集計 / 本部報告 / 発注・シフト | 店舗レポートAI・本部報告AI | 本部間接人件費 / 店舗管理工数 |
| 医療周辺 | 各種書類作成 / 問い合わせ対応 / シフト管理 | 書類作成AI・問い合わせAI | 事務職の残業時間 |
| 介護 | 介護記録 / ケアプラン作成 / 請求事務 / 採用 | 記録AI・採用AI | 記録時間 → 直接介護時間比率 |
| 物流 | 荷主対応 / 請求・照会 / 安全書類 | 問い合わせAI・書類AI | 事務工数 / 配車担当1人あたり車両数 |
| 建設 | 見積作成 / 施工計画 / 安全書類 / 下請管理 | 見積AI・書類AI | 見積提出リードタイム → 受注率 |
| 人材 | 求人票作成 / スカウト文 / 面談記録 | 採用AI・求人票AI | CA1人あたり決定数 |
| 多店舗サービス | 店舗報告 / マニュアル更新 / 研修 / SV業務 | 店舗レポートAI・マニュアルAI | SV1人あたり担当店舗数 |

> **経営指標に接続できない業務は提案しません。** 「効率化できます」では300万円のAssessmentは売れません。「SV1人あたりの担当店舗数が8店舗から12店舗になります」なら売れます。

## 4. ICPスコアリングシート（商談前に必ず埋める）

**合計70点未満の企業は追いません。** 例外を作ると、営業リソースが薄まって全体が失速します。

| # | 評価項目 | 配点 | 判定基準 |
|---|---|---|---|
| 1 | 売上規模 | 15 | 30〜500億円=15 / 500〜1,000億円=8 / 30億円未満=0 |
| 2 | 従業員数 | 10 | 100〜2,000名=10 / それ以外=3 |
| 3 | 重点8業種に該当 | 15 | 該当=15 / 隣接=8 / 非該当=0 |
| 4 | **ホワイトカラー比率** | 15 | 事務・管理・企画職が全社の20%以上=15 |
| 5 | **AI専門部署の不在** | 15 | 専門部署なし=15 / 情シス内に担当あり=8 / 専門部署あり=0 |
| 6 | **経営層へのアクセス** | 15 | 社長・役員と直接会える=15 / 経営企画まで=10 / 部門長止まり=0 |
| 7 | IT投資予算 | 10 | 年3,000万円以上=10 / 1,000〜3,000万円=5 / 未満=0 |
| 8 | 意思決定の速さ | 5 | オーナー系・即決可=5 / 稟議3ヶ月以内=3 / それ以上=0 |
| | **合計** | **100** | **70点以上で商談着手** |

**項目4・5・6が本質です。** ここが低い企業は、規模が大きくても成約しません。

## 5. 狙わない企業（除外条件）

**次のいずれかに該当したら、引き合いが来ても丁重に断ります。**

| # | 除外条件 | 理由 |
|---|---|---|
| 1 | **社内にAI専門部署・データサイエンスチームがある** | 内製と比較されます。OneWayの価値は「専門部署の代わり」です |
| 2 | 情報システム部が強く、内製志向が明確 | 基盤を自作されます。パートナーにはなり得ても顧客にはなりません |
| 3 | 売上1,000億円超 | 大手コンサルの陣地。設立年数と体制で負けます（Y4以降に再検討） |
| 4 | 年間IT投資が1,000万円未満 | Level 1（300万円）すら決裁できません |
| 5 | 経営層に会えず、現場担当が窓口 | **最も危険。** ツール比較・相見積もりに落ちます |
| 6 | 「PoCを無料でやってほしい」と最初に言う企業 | 投資意思がありません。工数だけ奪われます |
| 7 | 生成AIの利用を全社禁止している | 説得コストが投資対効果に見合いません |

> **除外条件5は特に厳格に運用します。** 現場担当が窓口の案件は、即断るのではなく「経営層への説明機会をいただけるなら進めます」と条件を出します。断られたら降ります。

## 6. 意思決定者マップ — 誰に、何を言うか

**同じ提案を全員に話してはいけません。** 役職ごとに刺さる言語が違います。

| 役職 | 関心事 | 使う言語 | 使ってはいけない言語 |
|---|---|---|---|
| **社長・オーナー** | 事業成長 / 人手不足 / 競合との差 | 「人を増やさずに売上を伸ばす構造を作ります」 | 技術用語・ツール名 |
| **取締役・役員** | 部門KPI / 予算対効果 | 「年間◯◯時間、金額換算◯億円の余力を作ります」 | 「効率化」「DX推進」 |
| **経営企画** | 中期計画への組み込み / 説明責任 | 「3年ロードマップと投資回収計画を提出します」 | 曖昧な効果予測 |
| **DX責任者・情シス** | 実現可能性 / セキュリティ / 運用負荷 | 「ガバナンス・監査ログ・権限管理を標準装備しています」 | 「とりあえず試しましょう」 |
| **現場部門長** | 自部門の負荷 / 使いやすさ | 「◯◯業務が半分になります」 | 経営全体の話（響きません） |

**攻略順序：社長 or 経営企画 → 役員合意 → DX責任者・情シスの技術審査 → 部門長の協力取り付け**

**逆順は失敗します。** 現場から積み上げると、必ず「予算がない」で止まります。

## 7. ターゲットリストの作り方（Dream 100 の実務）

### 7.1 リストソース

| ソース | 取得方法 | 優先度 |
|---|---|---|
| **既存クライアント・紹介** | Hiroの既存関係 | **最優先**（与信の代替になります） |
| 週末AI活用実践塾（Executive AI Camp）受講企業 | 既存リスト | 最優先 |
| 業界団体の会員名簿 | 各業界団体（不動産 / 介護 / 物流 / 建設 等） | 高 |
| 地銀・信金のビジネスマッチング | 提携交渉 | 高（与信を借りられます） |
| 税理士法人・会計事務所の顧問先 | 提携交渉 | 高 |
| 企業データベース | 売上・従業員数・業種で条件抽出 | 中 |
| 業界紙・専門メディア | 経営者インタビュー掲載企業 | 中 |
| 上場企業の中期経営計画 | IR資料で「生産性向上」「人手不足」に言及している企業 | 中 |

### 7.2 リスト管理項目

```
企業名 / 業種 / 売上 / 従業員数 / ICPスコア /
接触ルート（直接・紹介・パートナー） /
キーパーソン（氏名・役職） / 接触状況 /
現在のLevel（0〜5） / 次アクション / 次回接触日
```

### 7.3 初年度の目標数

| 段階 | 目標 |
|---|---|
| リスト化（ICP 70点以上） | **200社** |
| 一次接触 | 100社 |
| Executive AI Briefing（Level 0）実施 | 30社 |
| Enterprise AI Assessment（Level 1）受注 | 12社 |
| Platform（Level 3以上）受注 | 5社 |

## 8. この帯特有の購買プロセスと突破法

**売上30〜500億円の企業は、大企業ほどではないにせよ、確実に購買プロセスを持っています。** 想定して準備します。

| 関門 | 何が起きるか | 突破法 |
|---|---|---|
| **与信審査** | 設立年数・資本金・決算期数を見られます | 紹介経由で入る / 増資を検討 / 実績企業名を出せる状態にする |
| **反社・取引先審査** | 標準的なチェック | 事前に必要書類を揃えておきます |
| **情報セキュリティチェックシート** | 100〜300問の回答を求められます | **回答集を事前に作成**（[11-open-questions.md](11-open-questions.md)） |
| **稟議** | 3〜6ヶ月かかることがあります | **Assessment報告書を稟議書の下書きとして提供します** |
| **相見積もり** | 他社比較を求められます | 比較不能なカテゴリで提案します（[01-positioning.md](01-positioning.md) 4.4） |
| **情シスの技術審査** | セキュリティ・可用性・データ取扱いを問われます | セキュリティホワイトペーパーを提出します |

> **最強の突破法は「Assessment の最終報告を経営会議で行う」ことです。**
> 経営会議で社長が「やる」と言った案件は、購買プロセスが一気に加速します。これが Level 1 を300万円で売る最大の理由です（[03-product-ladder.md](03-product-ladder.md)）。
