# 08. 実行プラン：5年ロードマップと最初の90日

> **本ドキュメントは、01〜07で定義した戦略を時間軸に落としたものです。**
> 毎月の経営レビューは、この文書のKPI表を開いて行います。

|---|---|
| 最終更新 | 2026-08-29 |
| ステータス | ドラフト |
| 更新トリガー | 毎月（実績反映）/ 各Phase完了時 |

## 0. 結論

1. **Y1でやることは3つだけです。** ① 90日MVPを作る ② Assessment を8社に売る ③ Platform を2社に入れる。**それ以外はやりません。**
2. **1期に着手する事業レイヤーは1つまで。** 構想が壮大なほど「全部同時」の誘惑が強くなります。ここで失敗する会社が最も多い。
3. **Y5の目標：従業員25名・総売上10.5億円・ARR 8億円・企業価値40〜64億円。** デリバリーの55%をパートナーが担うことで、この人数で成立させます。

## 3. Phase 1：初号案件と検証（2026年12月〜2027年8月）

| 領域 | やること | 目標 |
|---|---|---|
| **販売** | Briefing 20社 / Assessment 8社 / PoV 2社 / Platform 2社 | 総売上1.02億円 |
| **販売** | **デザインパートナー2社**（Platform を定価の50〜70%で提供） | 事例公開許諾を契約書に明記 |
| **開発** | ① AI Catalog v1（横断エージェント10種） | 実業務で稼働 |
| **開発** | ④ Control Center v1（利用量・削減時間・ROI） | 経営会議で報告できる |
| **検証** | 全Platform顧客で **90日以内に経営会議報告** を完遂 | Time to Value 90日 |
| **検証** | **週次アクティブ利用率40%以上** を全社で達成 | 更新の先行指標を確保 |
| **資産化** | 案件知見をテンプレート・チェックリスト・想定問答集に変換 | Catalog 20種到達 |

> **Phase 1 の真の成果物は売上ではありません。**
> **①再現可能な Assessment 手順書 ②顧客別コードゼロで動く Platform ③公開できる事例2本。この3つです。**

**Phase 1 の合否判定（2027年8月時点）：**

| 判定項目 | 合格ライン |
|---|---|
| Platform 顧客 | 2社が稼働し、週次アクティブ利用率40%以上 |
| 商品の再現性 | **顧客別コードを1行も書かずに2社目を設定できたか** |
| Assessment の量産性 | Hiro以外のメンバーが工程3〜7を実施できたか |
| 事例 | 実名または業種特定可能な形で公開できる事例が2本 |

**「顧客別コードを書いてしまった」場合は、Y2の拡販を延期してでも共通化を優先します。** ここを妥協すると、EL3以降が永久に始まりません。

## 8. 組織・採用トリガー

| 発火条件 | ポジション | 理由 |
|---|---|---|
| **今すぐ** | 業務委託：ソリューションアーキテクト（週2〜3日） | 4プロダクトのMVP。ここが遅れると全計画が遅れます |
| **Assessment 3件受注** | 業務委託：アナリスト（業務棚卸し担当） | Assessment はHiroの時間を最も食います |
| **ARR 5,000万円** | 正社員：カスタマーサクセス 1名 | Hiroが CS を兼務できる限界。更新率が落ち始めます |
| **ARR 1億円** | 正社員：ソリューションアーキテクト 1名 | オンボーディング同時並行3社が限界 |
| **ARR 2億円** | 正社員：セールス 1名 / プロダクトマネージャー 1名 | Hiroを営業から外し、設計と戦略に戻します |
| **ARR 3.5億円** | パートナーマネージャー 1名 | EL4の運営に専任が必要になります |

**原則：固定費を先に上げません。** Y2までは業務委託を主体に、伸縮できる体制を維持します。

## 11. リスクと反証

| # | リスク | 深刻度 | 潰し方 |
|---|---|---|---|
| 1 | **顧客ごとにコードを書き、受託に逆戻りする** | **最大** | 「顧客別コードゼロ」を社内絶対ルール化。Phase 1 の合否判定項目に組み込み済み |
| 2 | **2年目に更新されない** | **最大** | 週次アクティブ利用率40%を死守。Control Center で経営者に効果を常時提示 |
| 3 | Assessment が Hiro に属人化し、量産できない | 高 | 9工程を手順書化。工程3〜7をアナリストに委譲（Phase 1 判定項目） |
| 4 | 与信・購買審査で落ちる | 高 | 紹介ルート優先。ホワイトペーパー先行。Y3でISMS取得 |
| 5 | AI原価の高騰で粗利が消える | 高 | 同梱クレジットは基本料金の15%以内。モデルルーターで最適化。原価率20%超でアラート |
| 6 | **モデルベンダーが同等機能を直接提供する** | 高 | 堀は技術ではなく **業種別の型 × ガバナンス × 経営可視化**。基盤モデルには一切投資しません |
| 7 | Level 4/5 の価格整合が未決着のまま提案する | 中 | Phase 0 W1 で決着（[03-product-ladder.md](03-product-ladder.md) 第7章） |
| 8 | 全レイヤーを同時に立ち上げて失速する | 中 | **1期1レイヤー**を厳守 |
| 9 | パートナーがOneWayを迂回する | 中 | EL3（部品）とEL2（土台）を握る。EL5（認定）で正統性を独占 |
| 10 | 受託収入の減少でキャッシュが詰まる | 中 | Y2まで受託を残す。年額前払いを死守。固定費の先行増加を禁止 |
