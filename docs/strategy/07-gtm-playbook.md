## 2. 絶対に言ってはいけないこと

| ❌ 禁句 | なぜダメか | ✅ 代わりに言うこと |
|---|---|---|
| **「生成AIについて、何かお困りごとはありますか？」** | **ツールベンダーの質問です。** 経営者は「特にない」で終わらせます | 「御社の中期計画で、いま一番人手が足りていないのはどの領域ですか」 |
| 「AIで業務効率化しませんか」 | 「効率化」は経営者の言葉ではありません | 「人を増やさずに売上を伸ばす構造を作ります」 |
| 「まずは無料でPoCをやってみましょう」 | ラダーが崩壊し、投資意思のない客に工数を奪われます | 「まず4〜6週間で、御社の適用領域を数字にします」 |
| 「ChatGPTとClaudeを使い分けて…」 | 経営者は道具の話に興味がありません | 「用途ごとに最適なAIを自動で振り分けます。選定は当社が責任を持ちます」 |
| 「DXを推進しましょう」 | 中身のない言葉。ブランドボイスのNG表現です | 具体業務と具体数値で語ります |
| 「他社事例では〜」だけで終える | 自社の話にならないと動きません | 「同じ計算を御社でやると、こうなります」 |

> **最初の30秒で「ツールベンダー」と判定されたら、その商談は終わりです。**
> **経営課題から入り、AIの話は最後まで出しません。**

## 3. 初回面談（60分）の設計

### 3.1 構成

| 時間 | 内容 |
|---|---|
| 0-5分 | 自己紹介。**「開発会社ではありません。設計事務所です」**（[01-positioning.md](01-positioning.md) 第3章のアナロジー） |
| 5-25分 | **経営課題のヒアリング**（下記4問） |
| 25-40分 | 同業種の適用領域マップを提示。「御社ならこうなります」 |
| 40-50分 | 想定される経済効果のレンジを口頭で提示 |
| 50-60分 | Level 0（Briefing）または Level 1（Assessment）の提案 |

### 3.2 経営課題ヒアリングの4問

**この4問だけで、ICPスコアと提案の入口が決まります。**

```
Q1. 中期経営計画で掲げている売上・利益目標は何ですか。
    そこに対して、いま最大のボトルネックはどこですか。

Q2. その目標を達成するために、あと何人採用が必要ですか。
    その採用は、実際にできそうですか。

Q3. 御社のホワイトカラー部門で、
    「この業務は本来こんなに時間をかけるべきではない」
    と感じているものは何ですか。

Q4. AIについて、これまで社内で何か試したことはありますか。
    それは今どうなっていますか。
```

**Q2が最も効きます。** 「採用できない」と答えた瞬間、AIは**コスト削減の話から、成長制約の解決の話**に変わります。

**Q4で「PoCをやったが止まっている」と答えたら、最良の見込み客です。**
すかさずこう言います：

> **「それは技術のせいでも、担当者のせいでもありません。運用の型を持たないまま作ったからです。」**

（過去の失敗を免罪し、原因を古い手段に帰属させます）

## 4. Executive AI Briefing（Level 0）の設計

**半日〜1日。社長 + 役員3〜8名。50〜100万円。**

| # | セッション | 時間 | 内容 |
|---|---|---|---|
| 1 | 業界の現在地 | 30分 | 同業種でいま何が起きているか。**危機感の共有** |
| 2 | 他社事例 | 30分 | 同業・近接業種の具体事例（数値付き） |
| 3 | **自社への当てはめ（ワーク）** | 60分 | **役員自身に、自部門の業務を洗い出させます** |
| 4 | 3年後に起きること | 30分 | 何もしなかった場合の競争上の位置 |
| 5 | 選択肢の提示 | 30分 | 内製 / 個別開発 / OneWay型 の3択と、それぞれの時間軸・コスト |

**セッション3が肝です。** 役員自身が自部門の業務を書き出すと、**「うちにもこんなにあるのか」**という当事者化が起きます。他人に説明されるのではなく、自分で気づかせます。

**クロージング：**

> 「今日出てきたのは、およそ30業務です。実際には100業務以上あります。
> それを4〜6週間で全部洗い出し、金額に換算し、3年間の投資計画まで作るのが Assessment です。」

## 5. Assessment の数字の作り方【最重要】

### 5.1 算出プロセス

```
STEP 1  業務棚卸し
        部門ごとに「業務名 / 実施者数 / 頻度 / 1回あたり時間」を記録
        → 年間工数 = 実施者数 × 年間頻度 × 1回あたり時間

STEP 2  AI適用可能性の3軸評価
        ① 定型度（手順が決まっているか）
        ② 判断の複雑さ（人間の裁量がどれだけ必要か）
        ③ データの利用可能性（必要な情報が社内にあるか）
        → A（高）/ B（中）/ C（低）に分類

STEP 3  削減率の適用
        A = 70% / B = 40% / C = 15%
        → 年間削減可能時間 = Σ（業務ごとの年間工数 × 削減率）

STEP 4  金額換算
        部門別の人件費単価（給与+法定福利+間接費）を適用
        → 推定経済効果（理論値）

STEP 5  ★実現率の適用★
        初年度に実際に稼働する範囲を保守的に見積もる
        → 初年度実現効果 = 理論値 × 実現率（推奨 30%）

STEP 6  投資回収期間
        = 初年度投資額 ÷（初年度実現効果 ÷ 12）
```

### 5.2 報告書サマリーの標準フォーマット

```
┌─────────────────────────────────────────────┐
│  AI適用候補業務            87業務              │
│  年間削減可能時間          24,000時間          │
│  推定経済効果（理論値）    年間 1.4億円         │
│  ─────────────────────────────────────────  │
│  初年度実現率              30%                 │
│  初年度実現効果            年間 4,300万円       │
│  初年度AI投資              3,000万円            │
│  投資回収期間              8.3か月              │
│  ─────────────────────────────────────────  │
│  3年累計経済効果           2.8億円              │
│  3年累計投資               8,000万円            │
│  3年ROI                    3.5倍                │
└─────────────────────────────────────────────┘
```

### 5.3 【極めて重要】実現率を必ず明示すること

**理論値の1.4億円だけを提示すると、投資回収期間は2.6ヶ月になります。この数字はCFOに信用されません。**

| | 実現率を書かない場合 | **実現率を明示する場合** |
|---|---|---|
| 提示する回収期間 | 2.6ヶ月 | **8.3ヶ月** |
| CFOの反応 | 「そんなうまい話はない」 | **「保守的に見てもこれなら通る」** |
| 稟議での扱われ方 | 数字の妥当性で紛糾します | 前提が明示されているので議論が進みます |

> **自社の数字を自ら割り引いて見せることが、300万円の報告書に信頼性を与えます。**
> **理論値を大きく、実現値を保守的に。この2段構えが提案書の型です。**

### 5.4 削減時間だけで終わらせない

**時間削減ROIだけでは「浮いた時間は何に使うのか」と必ず突っ込まれます。** 必ず売上寄与指標を併記します。

| 業種 | 併記する売上寄与指標 |
|---|---|
| 不動産 | 反響初動対応時間の短縮 → 成約率の改善 |
| 建設 | 見積提出リードタイムの短縮 → 受注率の改善 |
| 人材 | CA1人あたり決定数の増加 |
| 小売・多店舗 | SV1人あたり担当店舗数の増加 → 出店余力 |
| 物流 | 配車担当1人あたり車両数の増加 |

## 6. 経営会議での最終報告（Assessment の商品価値の本体）

**メール納品を禁止します。契約書に「経営会議での報告」を明記します。**

| 時間 | 内容 |
|---|---|
| 0-10分 | 結論サマリー（第5.2節のボックス1枚） |
| 10-25分 | 業務棚卸しの結果（部門別の適用候補と工数） |
| 25-35分 | AI Architecture 設計（7層図で自社構成を提示） |
| 35-45分 | セキュリティ・データ評価の結果と対応方針 |
| 45-60分 | **3年ロードマップと初年度投資計画** |
| 60-75分 | 質疑 |
| 75-80分 | **次の意思決定事項の提示**（＝Level 2 / 3 の提案） |

**この場で意思決定させることが目的です。** 「持ち帰って検討します」で終わらせないため、最後のスライドは必ず**「次に決めていただきたいこと」**にします。

> **300万円のAssessmentが作り出す意思決定の転換：**
> ❌ 「システムに3,000万円払うか？」（コストの意思決定・購買部門の管轄）
> ✅ **「1.4億円の経済効果を取りにいくか？」**（投資の意思決定・経営会議の管轄）

## 7. 想定問答（Three Secrets の破壊）

### Secret 1 — Vehicle：「AIは実務では使えない。またPoCで終わる」

> **「PoCが止まる理由は3つで、すべて技術以外です。**
> **① 運用の型がない ② ガバナンスが通らない ③ 効果が測れない。**
> **当社が提供するのは、この3つを埋める基盤です。だから90日で本番稼働します。」**

補強材料：他社の90日レポート実物 / Control Center の実画面（匿名化）

### Secret 2 — Internal：「うちにはAI人材がいない」

> **「AI人材は不要です。必要なのは推進者2名だけで、その育成も契約に含みます。**
> **御社の社員は"使う側"でいてください。設計と運用は当社が持ちます。**
> **AI専門部署を作るなら、年間3,000万円の人件費と2年の採用期間が必要です。」**

### Secret 3 — External：「予算が通らない」

> **「これはIT予算の話ではありません。採用予算の話です。**
> **御社は来年、あと◯名の採用を計画されています。その1名分の人件費で、部門全体の処理能力が上がります。**
> **しかも採用と違い、3ヶ月で立ち上がり、辞めません。」**

**予算の出所を「IT予算」から「人件費・採用予算」に付け替えさせるのが、この帯の企業への最も効く切り口です。**

**第2の破壊材料：補助金レバレッジ（ライトアップ型・[12](12-benchmark.md) 参照）**

> **「省力化投資補助金など、御社が対象になり得る制度があります。採択されれば投資回収はさらに早まります。**
> **ただし当社は補助金ありきの提案をしません。補助金ゼロでも回収8.3ヶ月で設計し、採択されれば上振れ、という順序です。申請は提携の認定支援機関が担当します。」**

※「必ず通ります」「実質無料」は禁句です。ファイアウォール5原則（[12](12-benchmark.md) 2.4）を厳守します。

### Secret 1 への追加問答：「LayerXのAi Workforceと何が違うの？」

> **「対象と階層が違います。Ai Workforceは大企業のドキュメント処理を自動化する優れたプラットフォームです。**
> **当社は売上30〜500億円の中堅企業に、人とAIを一つの労働力として設計する経営OSを提供します。**
> **当社のレイヤーでは、文書処理だけでなく、御社の判断ルール・権限・投資対効果まで管理します。」**

## 8. リード獲得チャネル（優先順）

| # | チャネル | 具体アクション | 想定リード数/年 |
|---|---|---|---|
| 1 | **既存関係・紹介** | 既存クライアント / Executive AI Camp受講企業への個別提案 | 40社 |
| 2 | **業界団体での登壇** | 重点8業種の団体・研究会でのセミナー | 60社 |
| 3 | **金融機関との提携** | 地銀・信金のビジネスマッチング、取引先向けセミナー | 40社 |
| 4 | **士業との提携** | 税理士法人・会計事務所の顧問先紹介 | 30社 |
| 5 | 経営者コミュニティ | 若手経営者団体・業界別経営者会 | 20社 |
| 6 | オウンドメディア | 業種別の適用事例記事・ホワイトペーパー | 10社 |

**チャネル2・3・4が、この帯の企業への王道です。** 広告は使いません。**この価格帯の意思決定は、信頼の経路でしか動きません。**
