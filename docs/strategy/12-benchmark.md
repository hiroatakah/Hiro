# 12. ベンチマーク分析：LayerX × ライトアップ

## 0. 結論：2社から移植するのは「別々のエンジン」

| | LayerX から移植するもの | ライトアップから移植するもの |
|---|---|---|
| 役割 | **単価と信用のエンジン**（エンタープライズで高く売る技術） | **量産と獲得のエンジン**（営業人員なしで見込み客を集める技術） |
| 核 | コンパウンド戦略／灯台顧客／信用の借景／公開文化 | 診断入口／補助金レバレッジ／代理店網／ウェビナー量産／ストック化 |
| OneWayでの適用先 | Level 3〜5（Platform）の売り方・作り方 | Level 0〜1（Briefing / Assessment）への集客導線 |

**LayerXは「上で高く売る」、ライトアップは「下から大量に汲み上げる」。OneWayの6階建てラダーは、この2つを1本に接続する構造です。**

## 1. LayerX 分析

### 1.1 事実（確認済みの一次情報）

| 項目 | 内容 |
|---|---|
| 主力事業 | バクラク（支出管理SaaS）／ Fintech ／ **Ai Workforce**（エンタープライズ向け生成AIプラットフォーム） |
| Ai Workforce の中身 | ノーコード・ノープロンプトでドキュメントワーク（PDF/Word/Excelの読解・整理・入力・照査）を自動化する生成AIプラットフォーム |
| 提携 | **日本マイクロソフトと開発・営業で連携。基盤はAzure** |
| 導入実績（公表） | 福岡銀行：ストラクチャードファイナンス契約管理で**年約7,000時間削減見込み**／JA三井リース：年18,000件の見積登録を**50%削減目標**／三菱HCキャピタル／三菱UFJ銀行 |
| コンパウンド戦略 | バクラクは2021年1月の請求書受取から開始し、**約半年に1プロダクトのペース**で2023年末までに6プロダクト。「プロダクト間連携の質そのものが商品」 |
| 文化・発信 | 行動指針・カルチャーデックを全面公開。経営陣・社員がnote/技術ブログで戦略を公開発信し、採用と信頼獲得の両方に使う |

### 1.2 機能している構造（5つ）

| # | 構造 | なぜ機能するか |
|---|---|---|
| L-1 | **コンパウンド戦略** | 1顧客に複数プロダクトを重ねる。CACは初回だけ払い、2個目以降はCACほぼゼロで単価が上がる。データ連携そのものが乗り換え障壁になる |
| L-2 | **灯台顧客（Lighthouse）** | 「福岡銀行で年7,000時間」という**固有名詞＋実数**の事例が、同業他社の稟議を通す最強の材料になる |
| L-3 | **信用の借景** | Microsoftとの共同開発・共同営業。スタートアップに欠ける「大企業の購買審査を通る信用」を、巨人から借りる |
| L-4 | **公開文化＝採用と信頼のフライホイール** | 戦略・文化・技術を公開発信する。候補者は入社前に文化を理解し、顧客は接触前に信頼を形成する。**営業と採用のCACを同時に下げる** |
| L-5 | **カテゴリーを言葉で作る** | 「コンパウンドスタートアップ」「Ai Workforce」という言葉自体を発明し、その言葉の定義者＝第一想起になる |

### 1.3 OneWayへの移植

| 移植元 | OneWayでの実装 | 反映先 |
|---|---|---|
| L-1 コンパウンド | **Company DNA を共通基盤に、AIOSモジュール（Catalog / Knowledge Hub / Governance / Control Center / Vertical Packs）を同一顧客に重ねる。** Level 3→4→5 の昇格＋追加Agentが「プロダクト追加」に相当。KPIはNRR | [03](03-product-ladder.md) / [04](04-architecture.md) |
| L-2 灯台顧客 | デザインパートナー第1・2号の効果を**「◯◯社：年◯,◯◯◯時間削減」の形式で実名公開**（契約書に公開許諾を組み込む）。業種は重点8業種から選び、同業種の稟議材料にする | [08](08-execution-plan.md) / [13](13-goal-plan-3y.md) |
| L-3 信用の借景 | Microsoft級は現時点で不可能。**代替：①地銀・信金との共同セミナー ②業界団体の公認・後援 ③会計事務所ネットワークとの提携** を「借りる信用」として使う。クラウド/AIベンダーのパートナープログラム加入も追求 | [13](13-goal-plan-3y.md) |
| L-4 公開文化 | **OneWayの隠れた最強資産はHiroのコンテンツ製造能力（B2C事業で実証済み）。** これをB2Bに転用：①「OneWay 羅針盤」（戦略・文化の公開版）②noteで導入プロセス・失敗込みの実装記事を週1本 ③YouTubeで経営者向けAIOS解説。競合の零細AIベンダーはこれができない | [13](13-goal-plan-3y.md) |
| L-5 カテゴリー創造 | **「Enterprise AI Operating System（Enterprise AIOS）」「AI Workforce Design」「Company DNA」「AI Value Ledger」という言葉を、定義ごと発信し続ける。** 言葉の初出・定義者であることを記録に残す（note初出日を管理） | [01](01-positioning.md) |

### 1.4 真似ないこと・注意点

- **LayerXの土俵（大企業×ドキュメント処理）では戦いません。** Ai Workforceはメガバンク・大手リース会社が顧客です。OneWayは売上30〜500億円の中堅×経営OS。**すみ分けを提案書で明示できるようにしておきます**（「LayerXさんとは何が違うの？」への回答を想定問答に登録）
- **名称衝突リスク：** 「Ai Workforce」はLayerXの製品名です。OneWayの「AI Workforce Design Company」という名乗りは**Designを核に据えて差別化**し、対外では「人とAIの労働力設計会社」と日本語を併記します。**商標調査が必須**（→ [11](11-open-questions.md) A-11）
- 彼らの人材密度（大手からの引き抜き採用）は現時点で再現不能。**公開文化だけ先に真似ます**（これは人数がいらない）

## 2. ライトアップ 分析

### 2.1 事実（確認済みの一次情報）

| 項目 | 内容 |
|---|---|
| 概要 | 東証グロース上場（6580）。ミッション「全国、全ての中小企業を黒字にする」 |
| 業績 | **2025年3月期：売上40.0億円（+44.2%）／営業利益7.2億円（+125.4%）／営業利益率18%。** 2026年3月期も増益予想 |
| 事業構造 | DXソリューション事業が主力（売上の約76%）：**Jシステム**（補助金・助成金の自動診断）／**Jコンサル**（IT・人材・マーケ・助成金の経営課題解決）／**JDネット**（全国の中小企業・士業による共同仕入れ・共同販売ネットワーク。月5万円から代理店開始可能） |
| 集客装置 | 補助金・助成金の**無料/低額診断**（月額3,000円程度の会員サービス）を入口に中小企業リストを大量獲得。**ウェビナー集客サービスは完全成果報酬でリード提供実績1万件超** |
| ⚠️ 重大な留意点 | **2026年3月、週刊誌が「人材開発支援助成金の不正受給指南」疑惑を報道**（疑惑段階。係争・行政処分の有無は要継続確認） |

### 2.2 機能している構造（5つ）

| # | 構造 | なぜ機能するか |
|---|---|---|
| W-1 | **「お金がもらえる入口」** | 通常の営業は「お金を払ってください」から始まる。ライトアップは**「お金がもらえるか診断します」から始まる**。見込み客が自分から来る。獲得コストが構造的に低い |
| W-2 | **診断の自動化** | Jシステムは自動診断。**人が動かずにリードを選別**し、人は投資意思のある客にだけ使う |
| W-3 | **代理店網（JDネット）** | 全国の中小企業・士業を「売り手」に変える。**営業人員を雇わずに営業網が広がり**、しかも会費・仕入れで先にお金をもらう |
| W-4 | **ウェビナー量産** | セミナーを高頻度・低コストで回し、常時リードを供給する。成果報酬型で外販すらしている |
| W-5 | **ストック収益化** | 月額会員・継続コンサル・代理店会費で、少額×多数の継続収益を積む |

**構造の本質：「診断→リスト→教育→クロスセル→代理店網で複製」。** これは実はブランソンのファネル（餌→フロント→ミドル→バック）の日本B2B実装であり、OneWayが既にB2Cで運用している型と同型です。

### 2.3 OneWayへの移植

| 移植元 | OneWayでの実装 | 反映先 |
|---|---|---|
| W-1 お金がもらえる入口 | **「AI投資 × 補助金」を提案に組み込みます。** 省力化投資補助金〈一般型〉は最大1億円・補助率1/2で、**資本金10億円未満・従業員500人以下の特定事業者（＝OneWayのICP下半分）が対象になり得ます。**「3,000万円の投資が、実質1,500万円になる可能性があります」は External反論（予算）の最強の破壊材料 | [07](07-gtm-playbook.md) |
| W-2 診断の自動化 | **「AI経営力スコア診断」（無料・オンライン10問・自動判定）を公開。** 結果表示で業界ベンチマークとの差分を見せ、Briefing/Assessmentへ誘導。※無料PoC禁止ルールと矛盾しません：**無料は自動診断まで。人が動くものはすべて有償** | [13](13-goal-plan-3y.md) |
| W-3 代理店網 | EL4（実装パートナー）はY3のままですが、**紹介パートナー網（税理士法人・会計事務所・診断士・地銀）はFY2027に前倒し**します。紹介手数料10〜15%を明文化。JDネットの「先に売り手を組織する」思想だけ先取り | [05](05-ecosystem-model.md) / [13](13-goal-plan-3y.md) |
| W-4 ウェビナー量産 | **月2回の「Enterprise AIOS 経営セミナー」を定常運転**（経営層限定・実名参加制）。士業・地銀との共催で集客を借りる。HiroのB2Cウェビナー運用力をそのまま転用 | [13](13-goal-plan-3y.md) |
| W-5 ストック化 | 診断→スコアレポート月次配信（無料）→リスト熟成。有償ストックはLevel 3以上で回収する設計を維持（中小向け少額課金はやらない：ICPが違うため） | [06](06-revenue-model.md) |

### 2.4 【最重要】絶対に真似ないこと — コンプライアンス・ファイアウォール

**ライトアップには2026年3月時点で助成金不正受給指南の疑惑報道があります。** 疑惑の真偽にかかわらず、この報道が示す教訓は明確です：**「補助金・助成金を営業の主軸に置くと、現場は必ずグレーゾーンに滑り落ちる」。**

OneWayの補助金活用ルール（違反は懲戒事由レベルの社内規範とします）：

| # | ルール |
|---|---|
| 1 | **補助金は「あれば使う」。提案の前提にしない。** 補助金なしでROIが成立しない案件は受注しません |
| 2 | **申請書類の作成・申請代行は、提携する認定支援機関・士業のみが行います。** OneWayは制度情報の提供と紹介まで |
| 3 | **「必ず通ります」「実質無料」という表現を禁止します。** 採択は保証できません |
| 4 | 受給を目的とした計画の粉飾・工数の水増しに関与した瞬間、**取引を打ち切ります**（顧客側から求められた場合を含む） |
| 5 | 補助金関連の売上比率を**全社売上の10%以下**に制限します（依存の構造化を防ぐ） |

**理由：OneWayは経営層に「信頼」で売る会社です。** ライトアップの主戦場（中小・大量・低単価）ならレピュテーション毀損に一定の耐性がありますが、**中堅企業の経営会議に入る会社は、一度の報道で全案件を失います。**

## 3. 2社の構造をOneWayの6階建てに接続する

```
【ライトアップ型：量産と獲得のエンジン】
  AI経営力スコア診断（無料・自動）
  月2回ウェビナー／士業・地銀の紹介網／補助金レバレッジ
        │
        ▼
  Level 0  Executive AI Briefing（50〜100万）
  Level 1  Enterprise AI Assessment（300万）★経営会議で報告★
        │
        ▼
【LayerX型：単価と信用のエンジン】
  Level 2  PoV → Level 3 Dept Platform → Level 4 Ent Platform → Level 5 EA
  コンパウンド（Company DNA上にモジュールを重ねる）
  灯台顧客の実数公開／信用の借景／公開文化
```

**下半分（獲得）はライトアップに学び、上半分（拡大）はLayerXに学ぶ。** どちらか片方だけでは、5,000万→1億→3億の成長カーブは作れません。
