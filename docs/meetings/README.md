## 書式ルール

1. ファイル名は `YYYY-MM-DD-<相手のスラッグ>.md`
2. 冒頭に **メタ情報テーブル**（日時／相手／当方／形式／テーマ／一次ソース）を置く
3. **サマリー（3行）** を議事録本体より先に書く（結論ファースト）
4. 原メモにない解釈・提案は「解釈」「提案」と明示し、事実と混ぜない
5. 末尾に **未決事項** と **次アクション** をチェックボックスで置く
