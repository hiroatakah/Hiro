# OneWay エンタープライズ戦略 OS

OneWay株式会社のエンタープライズAI事業に関する戦略の一次情報は、**すべて `docs/strategy/` に集約されています。**

## 使い方

**Step 1: 必ず `docs/strategy/README.md` を最初に読む。**
ワンページ・サマリー、3つの階層（EL / Level / T）の区別、文書一覧、絶対に守る5つのルールが載っています。

**Step 2: 依頼の内容に応じて該当文書を読む。**

| 依頼の種類 | 読む文書 |
|---|---|
| 会社の名乗り・ポジショニング・案件の受諾判断 | `01-positioning.md` |
| ターゲット企業・業種別攻略・意思決定者 | `02-icp-target.md` |
| 商品定義・Level・Land & Expand | `03-product-ladder.md` |
| 技術構成・開発優先順位・作らないもの | `04-architecture.md` |
| 事業レイヤー・エコシステム・中長期の打ち手 | `05-ecosystem-model.md` |
| 価格・課金・財務・値引き判断 | `06-revenue-model.md` |
| 営業・商談・Assessment の数字の作り方・想定問答 | `07-gtm-playbook.md` |
| ロードマップ・90日計画・KPI | `08-execution-plan.md` |
| 理論・参照事例（プラットフォーム戦略 / 認定経済 / AWS / Salesforce） | `09-strategy-reference.md` |
| 過去の決定と理由・未決事項 | `10-decision-log.md` |
| 未確認・要実測・検証中の仮説 | `11-open-questions.md` |
| ベンチマーク（LayerX／ライトアップ）・競合比較・補助金の扱い | `12-benchmark.md` |
| **売上目標・月次レビュー・四半期実行計画（5,000万→1億→3億）** | **`13-goal-plan-3y.md`（コミット計画の正）** |

**Step 3: 出力する。ただし下の禁則を必ず守る。**

**Step 4: 新しい決定・知見が出たら、該当文書に追記する。**
このナレッジベースは蓄積型です。決定は `10-decision-log.md`、商談知見は `07-gtm-playbook.md`、理論・事例は `09-strategy-reference.md` に追記します。

---

## 絶対に守る5つのルール

出力がこれらに反していたら、書き直してください。

1. **顧客ごとにコードを書かない** — 顧客別要件は設定・テンプレートで吸収する。破ると受託会社に戻ります
2. **現場担当を窓口にしない。経営層（社長・取締役・経営企画・DX責任者）に限定する**
3. **無料提案・無料PoCをしない** — 商品ラダー全体が崩壊します
4. **1期に着手する事業レイヤーは1つまで**
5. **未確認の数字を対外資料に書かない** — `11-open-questions.md` のA欄を必ず確認する

---

## 出力時の禁則

- **「AIコンサル会社」「AI開発会社」「AI導入支援会社」「DX推進パートナー」と名乗らない。** 名乗りは **Enterprise AI Architecture Company** です
- **「生成AIについて何かお困りごとはありますか」型の質問設計をしない。** 必ず経営課題から入ります（`07-gtm-playbook.md` 第3章）
- **改善策（もっと安く・もっと早く）として提案しない。** New Opportunity として提示します（`01-positioning.md` 4.4）
- **ROIを理論値だけで提示しない。** 必ず実現率（推奨30%）を明示します（`07-gtm-playbook.md` 5.3）
- **EL / Level / T の記号を混同しない**（`README.md` 第2章）
- **AWS Marketplace / Salesforce の価格・手数料・充当率を、確認せずに断定しない**（`11-open-questions.md` A欄）

## ブランドボイス

`oneway-proposal` スキルの `references/brand-voice.md` に従います。要点：

- 結論ファースト・断言調（「〜だと思います」「〜かもしれません」は禁止）
- 強い断言 + 具体的数値
- 「完璧より完了」「消費者から事業者へ」を底流に置く
- 1文40字以内を目安に。抽象的なコンサル用語だけの文を書かない
